# Current Product Behavior Register

This register describes the implemented AIPH3 prototype. Source coverage is not proof of executed checks or deployment. Task records document the checks that ran.

All application routes use the hash prefix. All personas share one local scenario. Role checks organize the simulation and do not provide security. Original backend behavior remains in Git history.

Stable IDs are retained, including explicit removed entries. The legacy duplicate EMP-10 has been consolidated rather than assigned an ambiguous second identity.

## Current implementation limits

The prototype uses simulated login and synthetic data. Portable static builds support local scenarios and manual review without contacting I02 endpoints. Optional OpenAI analysis and chat run through the local development server or explicitly enabled public Vercel Functions. Vercel WAF limits POST chat/analysis requests by IP; this does not secure persona data or impose a global provider spending cap. Only the selected synthetic materials are sent. Browser requests are bounded at 50 seconds and provider generation at 45 seconds. Full JSON exports include the saved scenario and recruiter notes, never provider credentials. Human testing, publishing, CI results and course approval must be verified separately.
